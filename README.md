## 📖 সারসংক্ষেপ (Overview)

**FreeWispr** হলো উইন্ডোজ ১০ এবং ১১-এর জন্য তৈরি একটি আধুনিক, প্রিমিয়াম এবং সম্পূর্ণ ফ্রি ও ওপেন-সোর্স ভয়েস টাইপিং সফটওয়্যার। এটি আপনার মুখের কথা শুনে সরাসরি যে-কোনো অ্যাক্টিভ উইন্ডোতে (যেমন: ব্রাউজার, নোটপ্যাড, ওয়ার্ড, কোড এডিটর, চ্যাট ইত্যাদি) স্বয়ংক্রিয়ভাবে নির্ভুলভাবে টাইপ করে দেয়।

> 💡 **Wispr Flow বা Superwhisper এর মতো পেইড সফটওয়্যারের সেরা ওপেন-সোর্স ও ফ্রি বিকল্প!**

## ✨ আকর্ষণীয় ফিচারসমূহ (Key Features)

- **🎙️ যেকোনো অ্যাপে অটো-পেস্ট (Universal Auto-Paste):** Chrome, VS Code, Word, Excel, Notepad, Telegram, Slack বা যেকোনো জায়গায় কার্সার রেখে কথা বলুন — নিমেষেই টাইপ হয়ে যাবে।
- **🇧🇩 বাংলা, ইংলিশ ও বাংলিশ স্মার্ট পলিশ (Smart Multilingual Polish):**
  - বাংলায় কথা বললে বাংলায় শুদ্ধ বানানে বিরামচিহ্নসহ সাজিয়ে দেয়।
  - ইংরেজিতে বললে নিখুঁত ইংলিশ গ্রামার ঠিক রেখে টেক্সট তৈরি করে।
  - বাংলিশে বললে ন্যাচারাল বাংলিশ টেক্সট ঠিক রাখে।
  - "উম্ম", "মানে", "uhh", "umm"-এর মতো ফিলার শব্দ স্বয়ংক্রিয়ভাবে বাদ দেয়।
- **🌊 রিয়েল-টাইম সাউন্ডওয়েভ উইজেট (Dynamic Floating Pill Capsule):**
  - স্ক্রিনের উপরে ভেসে থাকা আল্ট্রা-মডার্ন ড্র্যাগেবল উইজেট।
  - কথা বলার সাথে সাথে ড্যান্সিং অডিও ওয়েভফর্ম (Waveform Animation)।
  - মিনি এবং ফুল ভিউতে টগল করার সুবিধা।
- **⚡ মাল্টিপল এআই প্রোভাইডার সাপোর্ট (Multi-Provider Support):**
  - **Groq AI** (Whisper-large-v3 — আল্ট্রা ফাস্ট ও ফ্রি)
  - **OpenRouter AI** (Gemini, Llama 3, DeepSeek ইত্যাদি)
  - **OmniRoute / Custom Router** (Gemini Multimodal Single-Pass)
  - **OpenAI Official**
  - সার্ভার থেকে সরাসরি সব এআই মডেলের তালিকা ফেচ ও রিয়েল-টাইম সার্চ সুবিধা।
- **💾 পার্মানেন্ট কনফিগারেশন (Never Lose Settings):**
  - আপনার এপিআই কি (API Key), মডেল সিলেকশন ও সেটিংস উইন্ডোজের লোকাল অ্যাপডাটাতে পার্মানেন্টলি সুরক্ষিত থাকে। কম্পিউটার রিস্টার্ট দিলেও সেটিংস মুছে যায় না।
- **⌨️ গ্লোবাল শর্টকাট (Global Hotkeys):**
  - এক ক্লিকে বা কিবোর্ডের `F8` চেপে ভয়েস টাইপিং শুরু ও শেষ করুন।
  - `Esc` চেপে যেকোনো সময় রেকর্ডিং বাতিল করুন।
  - নিজের পছন্দমতো যেকোনো কিবোর্ড শর্টকাট সেট করার সুবিধা।
- **🚀 অটো-স্টার্ট অন বুট (Windows Auto-Start):**
  - উইন্ডোজ চালু হওয়ার সাথে সাথে স্বয়ংক্রিয়ভাবে ব্যাকগ্রাউন্ডে রেডি হয়ে থাকার সুবিধা।

## 📥 ডাউনলোড ও ইনস্টলেশন গাইড (Download from GitHub Releases)

আপনি যদি কোডিং না জানেন বা সরাসরি প্রস্তুত করা সফটওয়্যারটি ব্যবহার করতে চান, তবে নিচের সহজ ধাপগুলো অনুসরণ করুন:

### ধাপ ১: রিলিজ পেজ থেকে ডাউনলোড করুন
1. এই রিপোজিটরির ডানপাশের **[Releases](../../releases)** সেকশনে যান।
2. সর্বশেষ রিলিজ (Latest Release) থেকে **`FreeWispr-v1.1.0-win.zip`** বা **`FreeWispr Voice Assistant.exe`** ফাইলটি ডাউনলোড করুন।

### ধাপ ২: এক্সট্র্যাক্ট ও চালু করুন
1. যদি `.zip` ফাইল ডাউনলোড করে থাকেন, সেটি আনজিপ (Extract) করুন।
2. ফোল্ডারের ভেতর থাকা **`FreeWispr Voice Assistant.exe`** ফাইলে ডাবল ক্লিক করে চালু করুন।
3. স্ক্রিনে একটি সুন্দর ফ্লোটিং ক্যাপসুল উইজেট দেখতে পাবেন!

### ধাপ ৩: এপিআই কি (API Key) সেট করুন
1. উইজেটের গিয়ার (Settings) আইকনে ক্লিক করে **Control Center** খুলুন।
2. **Groq** অথবা **OpenRouter** নির্বাচন করে আপনার ফ্রি API Key বসিয়ে দিন এবং Save করুন।
3. যেকোনো অ্যাপ্লিকেশনে কার্সার রাখুন, কিবোর্ডের **`F8`** চাপুন এবং কথা বলা শুরু করুন!

## 🛠️ ডেভেলপারদের জন্য লোকাল সেটআপ (Run from Source)

আপনি যদি সোর্স কোড থেকে প্রজেক্টটি চালাতে বা মডিফাই করতে চান:

### পূর্বশর্ত (Prerequisites):
- [Node.js](https://nodejs.org/) (v18 বা তার পরবর্তী ভার্সন)
- [Git](https://git-scm.com/)
- উইন্ডোজ ১০ বা ১১ অপারেটিং সিস্টেম

### ইনস্টলেশন ধাপসমূহ:

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/your-username/windows-voice-typing-project.git

# ২. প্রজেক্ট ফোল্ডারে প্রবেশ করুন
cd windows-voice-typing-project

# ৩. স্বয়ংক্রিয় ইনস্টলার চালান (বা npm install করুন)
install.bat
```

### ডেভেলপমেন্ট মোডে রান করা:
```bash
npm run app
```
*(অথবা ফোল্ডারে থাকা `run.bat` ফাইলটিতে ডাবল ক্লিক করুন)*

### স্ট্যান্ডঅ্যালন উইন্ডোজ .EXE বিল্ড করা:
```bash
build_exe.bat
```
*(এটি স্বয়ংক্রিয়ভাবে `dist-electron/win-unpacked/FreeWispr Voice Assistant.exe` তৈরি করবে এবং ব্যাকগ্রাউন্ডে চালু করে দেবে)*

## ⌨️ ডিফল্ট শর্টকাটসমূহ (Hotkeys Cheat-Sheet)

| শর্টকাট | কাজ (Action) | বিবরণ |
| :--- | :--- | :--- |
| **`F8`** | **Start / Stop Recording** | ভয়েস টাইপিং শুরু বা শেষ করতে (সেটিংস থেকে পরিবর্তনযোগ্য) |
| **`Esc`** | **Cancel Recording** | বর্তমান রেকর্ডিংটি বাতিল করতে |
| **`Ctrl + Alt + M`** | **Switch AI Mode** | এআই মোড বা প্রোভাইডার টগল করতে |

   - আপনার GitHub রিপোজিটরিতে যান এবং **Releases > Draft a new release** বাটনে ক্লিক করুন।

   - জিপ ফাইলটি বা `.exe` ফাইলটি Attach binaries বক্সে ড্রপ করুন।
   - **Publish release** বাটনে ক্লিক করলেই সারা বিশ্বের মানুষ সরাসরি ডাউনলোড করতে পারবে!
